HOW TO UPLOAD WITH GITHUB DESKTOP
---------------------------------
1. Download this ZIP and extract it.
2. Open the extracted folder.
3. Copy the CONTENTS of the extracted folder into the ROOT of your existing palkin-singla-website repository.
   Do NOT copy the outer folder itself into the repo.
4. Windows may ask to merge folders / replace files. Choose YES.
5. In GitHub Desktop review the changed files.
6. Suggested commit message:
   Add Google Ads case study hub and 10 client case studies
7. Commit to main.
8. Push origin.
9. Netlify should deploy automatically.

CHECK AFTER DEPLOY
------------------
First open:
https://palkin-singla.netlify.app/case-studies/google-ads/

Then verify all 10 cards open their individual case-study pages.
Also check the Case Studies dropdown from Home/About/Services pages. It should show both Google Ads and Meta Ads collections.

SITEMAP SAFETY
--------------
This package intentionally DOES NOT overwrite sitemap.xml because your site already has scheduled blog URLs and other SEO work.
Use GOOGLE-ADS-CASE-STUDY-SITEMAP-ENTRIES.txt to add the new URLs to your existing sitemap later without removing anything already there.
