# SEO steps after deployment

The website code now includes unique page titles, meta descriptions, canonical URLs, crawl directives, social sharing metadata, internal service links, a current XML sitemap and structured data for Palkin Singla's professional services.

## 1. Deploy this complete folder

Upload the complete website folder to the existing Netlify project. Do not upload only `index.html`; the `assets` folder, portfolio pages, `robots.txt` and `sitemap.xml` must remain together.

After deployment, confirm these URLs open:

- https://palkin-singla.netlify.app/
- https://palkin-singla.netlify.app/robots.txt
- https://palkin-singla.netlify.app/sitemap.xml

## 2. Connect Google Search Console

1. Open https://search.google.com/search-console/
2. Choose **Add property**.
3. Select **URL prefix**.
4. Enter `https://palkin-singla.netlify.app/` exactly.
5. Choose the **HTML tag** verification method.
6. Copy the complete verification meta tag and add it inside the homepage `<head>`, then redeploy.
7. Return to Search Console and select **Verify**.

## 3. Submit the sitemap

Inside Search Console, open **Sitemaps** and submit:

`https://palkin-singla.netlify.app/sitemap.xml`

Then use **URL inspection** and request indexing for the homepage first, followed by the Google Ads, Meta Ads and SEO portfolio pages.

## 4. Measure performance

Connect Google Analytics 4 and verify that contact-form submissions are recorded as a lead event. Review Search Console every month for:

- Search queries and average positions
- Pages receiving impressions
- Click-through rate
- Indexing or Core Web Vitals issues
- Enquiries coming from organic search

## 5. Build authority

Code changes create the SEO foundation; rankings also need authority and fresh content. Keep the same name, services and website URL on LinkedIn, relevant professional profiles and reputable business directories. Publish useful case studies or articles consistently and link them to the relevant service portfolio page.

Recommended first articles:

1. Google Ads for Service Businesses: How to Improve Lead Quality
2. SEO vs Google Ads: Which Channel Should a Small Business Choose?
3. Common Meta Ads Mistakes That Increase Cost per Lead
4. How to Choose a Freelance Digital Marketing Specialist in India
5. Technical SEO Checklist for WordPress and Shopify Websites

## 6. Recommended domain upgrade

A permanent custom domain is preferable to relying on a free Netlify subdomain for long-term brand trust and SEO. When a custom domain is purchased, set one preferred HTTPS version, redirect the current Netlify URL to it, update canonical URLs and submit the new property and sitemap in Search Console.

No ethical SEO professional can guarantee the number-one position for a broad term such as “digital marketer.” Progress should be measured through impressions, relevant rankings, organic clicks and qualified enquiries over time.
