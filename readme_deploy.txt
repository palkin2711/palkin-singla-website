DEPLOY TO NETLIFY
1. Open the existing palkin-singla site in Netlify.
2. Go to Deploys and upload the final website ZIP (or drag the unzipped folder).
3. Keep the current site/project so the same netlify.app URL remains active.
4. After the deploy finishes, open the homepage and submit one test enquiry.
5. In Netlify, open Forms. The form name will be "contact".
6. To receive email alerts, add a form submission notification in Netlify.

CONTACT FORM
- The form uses Netlify Forms and does not require a separate server.
- Spam protection uses a hidden honeypot field.
- Successful submissions redirect to thank-you.html.

MAIN FILES
- index.html: redesigned homepage and working contact form
- linkedin_ads_portfolio.html: new LinkedIn Ads portfolio
- tiktok_ads_portfolio.html: new TikTok / PLAYHAUS case study
