PALKIN SINGLA — META ADS CASE STUDIES FINAL UPLOAD
===================================================

THIS ZIP IS THE FINAL CASE-STUDY INTEGRATION PACKAGE.
It is designed to be copied into the ROOT of your existing GitHub website repository.

------------
1. /case-studies/meta-ads/            — new Meta Ads Case Studies hub page
2. /case-studies/patent-prints/       — Patent Prints detailed case study
3. /case-studies/kilogear-meta-ads/   — Kilogear detailed case study

   - All Case Studies
   - Meta Ads Case Studies
9. All account-proof screenshots used by the five case studies
10. Shared case-study CSS and screenshot lightbox JS

UPLOAD WITH GITHUB DESKTOP
--------------------------
1. Extract this ZIP.
2. Open your local palkin-singla-website repository folder.
3. COPY THE CONTENTS inside this extracted folder into the repository root.
   IMPORTANT: copy the contents, not the outer folder itself.
4. Windows will ask to merge folders such as assets and case-studies. Choose Merge/Replace when asked.
5. In GitHub Desktop you should see new/changed files.
6. Commit message suggestion:
   Add Meta Ads case study hub and client case studies
7. Push origin.
8. Netlify should deploy automatically.

IMPORTANT SAFETY NOTE
---------------------
This package intentionally does NOT overwrite sitemap.xml because your blog builder/scheduled posts may already have newer sitemap entries. The new pages are internally linked and crawlable immediately.
A file called CASE-STUDY-SITEMAP-ENTRIES.txt is included with the six URLs you can later add to sitemap.xml outside the BLOG-SITEMAP markers.
